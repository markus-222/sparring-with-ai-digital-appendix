## Execution

The search comprises three components in line with vom Brocke et al. (2009): (a) database search across OpenAlex, Semantic Scholar, IEEE Xplore, ACM DL, AIS eLibrary and EBSCOhost; (b) known-item seeding from prior reading; (c) backward and forward snowballing on 16 seed papers.

| Source | Role | Method |
|--------|------|--------|
| **OpenAlex** | Primary (broad discovery) | Programmatic search via the API |
| **Semantic Scholar** | Secondary (strong arXiv coverage) | Programmatic search via the API |
| **IEEE Xplore / ACM DL / AIS eLibrary / EBSCOhost** | Manual supplement | Boolean search per query in the web interface, export as BibTeX |
| **Known-item seeding** | Recall safety net | Papers from preparatory reading not found by the sources above |

After the search, all records were deduplicated across sources and filtered by the venue list and the time window (Appendix A of the thesis).

### Snowballing Seeds

Snowballing (forward and backward, depth 1, via the Semantic Scholar API) started from 16 seed papers (selection described in Appendix A of the thesis).
