# Abschrift Bild: Stakeholder Map (`stakeholderMap.jpeg`)

*Abschrift des Bildinhalts für die Artefaktbewertung, erstellt mit Claude. Quadrant aus der Lage des Punkts abgelesen; Punkte nahe einer Trennlinie sind markiert.*

**Achsen:** Einfluss (niedrig → hoch, senkrecht) · Wissen über Problem und Arbeitsalltag (niedrig → hoch, waagerecht)

**Quadranten:** Informieren (Einfluss hoch, Wissen niedrig) · Eng einbinden (Einfluss hoch, Wissen hoch) · Beobachten (Einfluss niedrig, Wissen niedrig) · Bedarfe erheben (Einfluss niedrig, Wissen hoch)

**Wichtigkeit (Farbe):** hoch (rot) · mittel (orange) · niedrig (grau)

| Stakeholder | Quadrant | Wichtigkeit |
| --- | --- | --- |
| Geschäftsführung | Informieren (Einfluss am höchsten) | hoch |
| Controlling | Informieren | hoch |
| Betriebsrat | Informieren | mittel |
| Bereichsleitungen | Eng einbinden | hoch |
| PE | Eng einbinden (nahe Trennlinie Einfluss) | hoch |
| Teamleitung | Eng einbinden (nahe Trennlinie Einfluss) | hoch |
| IT-Services | Eng einbinden (nahe Trennlinie Einfluss) | mittel |
| Auftraggeber | Beobachten | mittel |
| LMS-Anbieter | Beobachten | niedrig |
| Verwaltung | Beobachten (nahe Trennlinie Wissen) | mittel |
| Bid-Management | Bedarfe erheben | mittel |
| Mitarbeitende | Bedarfe erheben | hoch |
| Werkstudis, Teilzeit | Bedarfe erheben | niedrig |
| Freelancer | Bedarfe erheben | niedrig |
